**The argument.** Windows Internals is the long-standing reference for how the Windows operating system works. It covers the structure of the system, processes and threads, memory management, security, storage and more. It is not a book to read cover to cover. It is the one to open when you need to know why Windows does what it does.

## Ideas worth keeping

- **System architecture**, from the kernel to the services that run on top.
- **Processes and threads**, and how Windows schedules them.
- **Memory management** in detail.
- **Services and startup**, which matter for software that runs on every student computer.

## Where it shows in Classroom Manager

A program that runs as a service on student computers has to cooperate with how Windows starts, schedules and secures such programs. This is the reference behind those decisions.

## Who should read it

Experienced Windows developers and administrators. It is a reference, not a first book.
