**The argument.** Good software comes from craft: care for details, small reversible steps, and tools that remove repetition.

**Ideas worth keeping.** Don't repeat yourself, automate what you do twice, fix problems when you find them, and keep changes easy to reverse.

**Where it shows in Classroom Manager.** One change per commit, an automated build and test run before every release, and scripted publishing instead of manual steps.
