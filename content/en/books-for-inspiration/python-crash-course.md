**The argument.** Python Crash Course teaches programming through projects. The first part covers the basics: variables, lists, loops, functions, classes, files and testing. The second part puts them to work in three projects: a small 2D game, data visualisation, and a web application built with Django. The author is a former high school teacher, and the explanations are patient.

## Ideas worth keeping

- **Learn by building.** Each idea is used straight away in a program that runs.
- **The basics, in order.** Variables, lists, loops, functions and classes, with exercises.
- **Testing from the start.** The book shows how to test your code, which many beginner books skip.
- **Three projects** that show what programming can produce, from a game to a web application.

## Where it shows in Classroom Manager

Classroom Manager is a Windows program written in C#, not Python, but the habits are the same: small programs, tests, and building real things. Python is the easiest place to learn them, and many IB Computer Science courses use it.

## Who should read it

Beginners of any age, IB students looking for a second source, and teachers who want a book to set as independent work.
