**The argument.** SICP, as it is known, is the long-time introductory text of the MIT Electrical Engineering and Computer Science department. It uses the Scheme language, but its subject is larger than any one language: how to control complexity with abstraction, how procedures and data can be combined, and how to write a program that interprets another program. A version is freely available on the MIT Press website.

## Ideas worth keeping

- **Abstraction** as the main tool against complexity.
- **Procedures and data** that build on each other.
- **Modularity and state**, and what changes when a program remembers things.
- **Interpreters and evaluators**: how a programming language itself is made.

## Where it shows in Classroom Manager

Its central message, that good design hides complexity behind simple interfaces, is the same idea that shapes how we structure Classroom Manager. It is a demanding read, so keep it for after the first programming book.

## Who should read it

Motivated students who want to understand programming deeply, and developers who want to revisit the foundations.
