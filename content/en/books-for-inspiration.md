We build software for teachers and school IT staff, and we read widely to do it well. This list is also a path for anyone who wants to learn how to build software like Classroom Manager, or to start a software company of their own: it begins with IB Computer Science course books and moves through programming, architecture, Windows and security, and starting a business. A short guide to the order is in [How to learn to build software like Classroom Manager](../blog/learn-to-build-software-like-classroom-manager/).

Each page says what the book argues, lists the ideas worth keeping, shows where they appear in Classroom Manager, and says who should read it. We write these notes in our own words, and we point to the book itself for the full argument.
