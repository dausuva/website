Impero Education Pro combines classroom management with safeguarding. Its page says it "combines learner well-being and device management to enhance digital learning, support IT administration, and monitor safeguarding issues effectively". The company behind it, Impero Solutions Ltd, now trades as **Ativion**, and the old Impero web address redirects to Ativion's site. Education Pro is built around **seeing what students do and flagging concerns**; Classroom Manager is built around the Windows lab itself, **without watching anyone's screen**.

Checked on 5 November 2026 against Ativion's Education Pro page and its education home page. Impero's own pages are short: they name capabilities but do not list individual tools, prices, system requirements or hosting details, so most rows below say "Not stated on the page read". We did not install or trial the product. Classroom Manager's column describes the current build; ask for a demo to see it.

## At a glance

| | Impero Education Pro | Classroom Manager |
|---|---|---|
| Built for | Learner well-being, device management and safeguarding, with classroom tools | Preparing, running a lesson in, and maintaining a Windows lab |
| Student screens | "Real-time visibility of every student's screen" | Deliberately none: no viewing, capture or recording |
| Safeguarding | "Real-time flags, active monitoring, and keyword detection" to highlight safeguarding incidents; "developed in line with Ofsted and ISI" | Not offered: no monitoring of what students type or view |
| Platforms | Windows, Chrome OS, macOS and iOS | Windows 10/11, 64-bit and 32-bit |
| Hosting | "Various hosting options"; not detailed on the page | No server and no cloud account: the teacher's Host connects straight to each Client over the school network |
| Price | Not stated on the page read | Published: free for up to 3 computers online at once; for a school, €499 the first year, then €299 a year; no per-PC charge |
| Related products | StudentKeeper (classroom wellbeing) and ContentKeeper (web filter), from the same company | None: one program with a Host and a Client |

## In the lesson and in the lab

| Task | Impero Education Pro | Classroom Manager |
|---|---|---|
| Watch student screens | Yes | Deliberately no |
| Classroom control, instructional and monitoring tools | "A range of" them; individual tools are not listed on the page read | Lock with a message, send a message, open a website or program, files out and back, Exam mode, recent files |
| Keyword detection and alerts | Yes | No |
| Web filtering | A separate product, ContentKeeper | Block lists for websites in Exam mode; not a filter |
| Install software, Windows Update, inventory, accounts, registry | Not stated on the page read | Yes: installers, MSI, winget, registry files; Windows Update; inventory with CSV export; accounts; registry |
| Schedules, command line, diagnostics | Not stated on the page read | Yes: schedules that catch up computers that were off, a command line, two health checkers and documented error codes |

## Which one fits

**Choose Impero Education Pro** if safeguarding and wellbeing monitoring sit with classroom control in your requirements, you need inspection-aligned reporting, and you run a mixed fleet with Chrome OS, Mac and iOS. Ask the vendor for the feature list, hosting options, price and system requirements, which its page does not give.

**Choose Classroom Manager** if the work is keeping a Windows lab ready: software, updates, settings, accounts and exam restrictions, files out and back, with a flat published price, help with the rollout, and no screen capture or keyword monitoring of minors to justify under GDPR.
