Faronics Insight is a commercial classroom management suite from Faronics. Its own page describes "an effective classroom management tool" that helps teachers run lessons and use real-time assessment, for schools of all sizes. Like NetSupport School and LanSchool it is built around **teaching with the students' screens in front of the teacher**. Classroom Manager shares the everyday lesson actions but is built around the Windows lab itself, **without watching anyone's screen**.

Checked on 5 November 2026 against Faronics' own Insight page. Insight was not installed or trialled for this comparison. Pricing, software languages, system requirements and any lab-maintenance tools are not stated on the page we read; the tables say so rather than guess. Classroom Manager's column describes the current build; ask for a demo to see it.

## At a glance

| | Faronics Insight | Classroom Manager |
|---|---|---|
| Built for | Teaching and assessment during a lesson, controlled "from one central computer" | Preparing, running a lesson in, and maintaining a Windows lab |
| Student screens | Thumbnails of every student device, with alerts for banned words, messages and raised hands | Deliberately none: no viewing, capture or recording |
| Platforms | "Windows, macOS, iOS, Android and Chrome OS" | Windows 10/11, 64-bit and 32-bit |
| Where it runs | Listed under "On-premise" in its site navigation; hosting is not described on the page | No server and no cloud account: the teacher's Host connects straight to each Client over the school network |
| Price | Not published: volume and education pricing are "not available online"; a quote through sales; a free trial is offered | Published: free for up to 3 computers online at once; for a school, €499 the first year, then €299 a year; no per-PC charge |
| Languages | Software languages not stated (the language selector covers the website) | English and Lithuanian, every text |
| Version on the page | Version 11 | The current build |

## In the lesson

| Task | Faronics Insight | Classroom Manager |
|---|---|---|
| Watch student screens | Yes, with alerts | Deliberately no |
| Share the teacher's screen, or a student's, with annotation | Yes, full screen or windowed | No |
| Blank or lock screens | Yes, with custom text or images | Yes, with your message |
| Chat and audio | Individual or group chat, optional student-to-student chat, one-way or two-way audio | A message to the students; no chat window |
| Take control of a student's computer | Yes, with their keyboard and mouse disabled meanwhile | No |
| Allow or block websites and apps, see history, stop running apps | Yes, including disabling InPrivate/Incognito browsing | Block lists for programs and websites in Exam mode, with sound, camera and USB storage |
| Tests and polls | True/false, multiple choice, short answer and essay questions with real-time results; yes/no and multiple-choice polls | No |
| Focus Mode, SSID whitelisting | Yes | Not in our feature list |
| Send and collect files; launch apps and websites on all devices | Yes | Yes: files to Desktop, Documents or any folder with an undo, collected by name pattern into a folder per student; saved buttons for websites and programs |
| Power options | Shut down, reboot, log on | Wake-on-LAN, restart, shut down, remote sign-in, each with a cancel |
| See what students changed in the last half hour and copy it | Not in its feature list | Yes: recent files by time and type |

## Looking after the computers

| Task | Faronics Insight | Classroom Manager |
|---|---|---|
| Install software, Windows Update, inventory, accounts, registry, scheduled tasks | Not stated on the page read | Yes: installers, MSI, winget and registry files; Windows Update with pause and resume; inventory with CSV export; accounts, processes, scheduled tasks, start-up programs, registry |
| Schedules that catch up computers that were off | Not stated on the page read | Yes |
| Diagnostics when something does not connect | Not stated on the page read | Two health checkers and documented error codes |

## Which one fits

**Choose Faronics Insight** if teaching with the students' screens is the point: watching with alerts, sharing and annotating screens, taking control, chat and audio, built-in tests and polls, and a mixed fleet with Mac, iOS, Android and Chromebooks. Ask Faronics for a quote and for the system requirements, which its page does not give.

**Choose Classroom Manager** if the work is keeping a Windows lab ready: software, updates, settings, accounts and exam restrictions, files out and back, with a flat published price, help with the rollout, and no screen capture of minors to justify under GDPR.

Some schools could use both: Insight for screen work in the lesson, Classroom Manager for the lab itself. See also [all comparisons]({{< relref "/school/compare" >}}) and [how the same jobs are done differently]({{< relref "/school/compare-approaches" >}}).
