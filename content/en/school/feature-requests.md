<p class="verdict"><strong>In one sentence:</strong> Classroom Manager is a focused tool for running and maintaining a Windows lab; some things people expect from classroom software it does not do today, and we say so here so you can decide before you start.</p>

We would rather you hear it from us than find out in the pilot. This is what Classroom Manager does **not** do today, checked against the current build, and where you may look instead.

## Not offered today

| What you might expect | Today | Where to look instead |
|---|---|---|
| Viewing, capturing or recording student screens | Not planned: a deliberate design choice, so there is no student-screen data to protect or justify | Products built around screens: see the [comparisons]({{< relref "/school/compare" >}}) |
| Chat between teacher and students | No: a message is one-way | Classroom suites such as [LanSchool]({{< relref "/school/compare-lanschool" >}}) or [Faronics Insight]({{< relref "/school/compare-faronics-insight" >}}) |
| Alerts by e-mail, SMS or webhook when a computer fails | No: the console shows each computer's state | A monitoring tool such as [Tactical RMM]({{< relref "/school/compare-tactical-rmm" >}}) |
| Limiting printing | No | A Windows policy, or a classroom suite that lists it |
| Battery status of student devices | No | LanSchool Air lists it |
| Allow-only lists in Exam mode | No: Exam mode blocks the programs and websites you list, plus sound, camera and USB storage | [Take a Test]({{< relref "/school/compare-windows-take-a-test" >}}) for a locked-down test |
| Tests and quizzes | No | Microsoft Forms, or a suite with built-in tests |
| Mac, Chromebook, iOS or Android | No: Windows 10 and 11 only | A mixed-device suite |

## Quick answers

<details><summary>Does Classroom Manager let a teacher see or record student screens?</summary><p>No. Viewing, capturing and recording student screens is a deliberate design choice and is not planned.</p></details>
<details><summary>Does Classroom Manager have a chat between teacher and students?</summary><p>No. A message from the teacher is one-way. A chat window is not offered today.</p></details>
<details><summary>Does Classroom Manager send alerts by e-mail, SMS or webhook?</summary><p>No. The console shows each computer's state, but it sends no alerts. For alerting, use a monitoring tool.</p></details>
<details><summary>Can Classroom Manager limit printing?</summary><p>No. Printing control is not offered today.</p></details>
<details><summary>Does Classroom Manager show the battery status of student devices?</summary><p>No. Battery status is not offered today.</p></details>
<details><summary>Does Exam mode support allow-only lists?</summary><p>No. Exam mode blocks the programs and websites you list, and can restrict sound, camera and USB storage. It is not a secure-exam environment or a single-app kiosk.</p></details>
<details><summary>Does Classroom Manager run on Mac, Chromebook, iOS or Android?</summary><p>No. It runs on Windows 10 and 11 computers only.</p></details>

## How to ask for something

Tell us the **job you are trying to do**, not only the feature: what you do today without it, and how many PCs and labs are affected. That helps us see whether it fits. Some requests, such as viewing student screens, conflict with a design choice, and we will say so; we do not promise dates.
