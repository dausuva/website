<details><summary>Does it need a cloud account or an internet connection?</summary><p>No cloud account or cloud control server is required. Host-to-Client control uses your school network. Optional release checks, software installers, Windows Update and runtime downloads may need internet access.</p></details>
<details><summary>Can a teacher watch students' screens?</summary><p>No. The product does not view, capture or record student screens. It does handle administrative information and the files you choose to send or collect.</p></details>
<details><summary>Is it a secure exam browser?</summary><p>No. Exam mode applies classroom restrictions; it is not a certified exam environment, a single-app kiosk or a guarantee against bypass. Test restrictions and their removal on your own configuration.</p></details>
<details><summary>Which Windows PCs can we use?</summary><p>Windows 10 and 11 configurations, including Home and Pro, have been tested. Confirm the exact edition, patch level, policies and required actions during your pilot. Operating-system vendor lifecycle and support are separate.</p></details>
<details><summary>Can we leave scheduled actions running overnight?</summary><p>Only while the Host application remains open. The schedule is not a separate unattended background service.</p></details>
<details><summary>Does Teacher Mode make an Admin key safe to share?</summary><p>No. Teacher Mode simplifies the interface. Use a separate Teacher key for restricted access; the Client enforces the credential's role.</p></details>
<details><summary>Will client updates recover automatically if a new version fails?</summary><p>No automatic post-start rollback is implemented. Signature and checksum checks are not a replacement for a tested recovery procedure and an independent route to the PCs.</p></details>
<details><summary>Does the software stop if support is not renewed?</summary><p>No. Existing installations keep working. Renewal pays for updates and support.</p></details>
<details><summary>Where can we download a trial?</summary><p>There is no public download. Request a demo first; afterwards we prepare a test package for your school.</p></details>
