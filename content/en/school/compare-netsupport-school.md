NetSupport School is a commercial classroom management suite from NetSupport, which calls it "the market-leading classroom management software". It is built around teaching with the students' screens in front of the teacher: monitoring, sharing, tests, and a **Technician's Console** for IT staff. Classroom Manager shares the everyday lesson actions but is built around the Windows lab itself, **without watching anyone's screen**.

Checked on 5 November 2026 against NetSupport School's own website (home page, features page and pricing page). NetSupport School was not installed or trialled for this comparison. Several things a buyer would want, such as supported Windows versions, security design and interface languages, were not stated on the pages we read; the tables say so rather than guess. Classroom Manager's column describes the current build; ask for a demo to see it.

## At a glance

| | NetSupport School | Classroom Manager |
|---|---|---|
| Built for | Teaching and monitoring during a lesson, with a console for IT staff | Preparing, running a lesson in, and maintaining a Windows lab |
| Student screens | Live views of screens, including dual monitors, with app, website and keyboard activity | Deliberately none: no viewing, capture or recording |
| Platforms | Windows, Mac, iOS/Android and Chrome, as its site navigation lists them; Linux is not mentioned | Windows 10/11, 64-bit and 32-bit |
| Price | A quote based on the number of devices; a "buy once and own forever" option; no list prices on its site | Published: free for up to 3 computers online at once; for a school, €499 the first year, then €299 a year; no per-PC charge |
| Support | Free support Monday to Friday and free online training, according to its pricing page; no implementation fees | Setup, onboarding and a year of updates and support included |
| Languages | Not stated on the pages read | English and Lithuanian, every text |

## In the lesson

| Task | NetSupport School | Classroom Manager |
|---|---|---|
| Watch student screens | Yes, adjustable thumbnails | Deliberately no |
| Show the teacher's screen, or a student's, to the class | Yes | No |
| Take over a student's screen | Yes (remote control) | No |
| Lock or blank screens | Yes, and keyboards and mice | Yes, with your message |
| Send a message | Yes, with clickable links | Yes |
| Open a website or a program on student computers | Yes | Yes |
| Send files and folders out, collect work back | Yes | Yes: to Desktop, Documents or any folder, with an undo; collected by name pattern, a folder per student |
| Allow only approved programs and websites, or block some | Yes | Yes: block lists for programs and websites in Exam mode, with sound, camera and USB storage |
| Tests, quizzes and surveys, marked automatically | Yes, including picture, audio and video questions | No |
| Virtual whiteboard, language lab | Yes | No |
| Power on or off, including PCs nobody is signed in to; sign users in and out | Yes | Yes: Wake-on-LAN, restart, shut down, remote sign-in, with a cancel |
| Printable register; reset students' Windows passwords | Yes | Local accounts can be created, enabled and given a new password; no register |
| See what students changed in the last half hour and copy it | Not in its feature list | Yes: recent files by time and type, copied in one click |

## Looking after the computers

| Task | NetSupport School | Classroom Manager |
|---|---|---|
| IT tools | A Technician's Console to support users and maintain devices; its individual tools are not itemised on the pages read | Install or uninstall software (installers, MSI, winget, registry files), Windows Update with pause and resume, hardware and software inventory with CSV export, accounts, processes, scheduled tasks, start-up programs, registry, wallpaper, themes, keyboard layouts, renaming, clock sync |
| Schedules that catch up computers that were off | Not stated on the pages read | Yes: clock sync, update checks, monthly backup of student work |
| Command line for scripts and Task Scheduler | Not stated on the pages read | Yes |
| Diagnostics when something does not connect | Not stated on the pages read | Two health checkers and documented error codes |

## Access and security

| | NetSupport School | Classroom Manager |
|---|---|---|
| Who may control | Not stated in detail on the pages read; it describes three graded user modes for teachers of different experience | Lab keys with Observer, Teacher or Admin roles, checked by each PC; keys can be limited to rooms |
| Encryption and certificates | Not stated on the pages read | TLS 1.2/1.3 always on, an approved certificate per PC, signed and checked frames |
| Cloud account or server | Not stated on the pages read | None: the teacher's Host connects straight to each Client over the school network |

## Which one fits

**Choose NetSupport School** if teaching with the students' screens is the point: watching, sharing and taking over screens, building tests and quizzes, a whiteboard, a language lab, or a mixed fleet with Mac, Chrome and mobile devices. Ask the vendor for a quote and for the system requirements, which its pages do not give.

**Choose Classroom Manager** if the work is keeping a Windows lab ready: software, updates, settings, accounts and exam restrictions, files out and back, with a flat published price, help with the rollout, and no screen capture of minors to justify under GDPR.
