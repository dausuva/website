LanSchool is classroom management software for K-12 schools. Its website says it is "backed by Lenovo" and calls LanSchool "a pioneer and innovator of classroom management software". It comes in two editions at one price: **LanSchool Classic**, hosted locally on the school's or district's servers, and **LanSchool Air**, hosted in the cloud. Both are built around **teaching with the students' screens in front of the teacher**; Classroom Manager shares the everyday lesson actions but is built around the Windows lab itself, **without watching anyone's screen**.

Checked on 5 November 2026 against LanSchool's own pages: the home page, the Classic page, the Air page and the purchasing page. LanSchool was not installed or trialled for this comparison. Prices, software languages and system requirements are not stated on the pages we read. Classroom Manager's column describes the current build; ask for a demo to see it.

## At a glance

| | LanSchool | Classroom Manager |
|---|---|---|
| Built for | Guiding learning, collaboration and focus in a lesson, with monitoring and safety tools | Preparing, running a lesson in, and maintaining a Windows lab |
| Student screens | Real-time thumbnails of every student screen, or one at full size; snapshots | Deliberately none: no viewing, capture or recording |
| Editions | Classic: "locally hosted … on your school or district's servers", for Mac, Windows and mixed devices. Air: cloud-based, for Mac, Windows, Chromebooks and mixed devices | One program: no server, no cloud account |
| Platforms | Mac, Windows, Chromebooks; iOS and Android are not mentioned | Windows 10/11, 64-bit and 32-bit |
| Price | "Single SKU pricing": two license options for one price, and no extra fee if your hosting plans change; a quote or purchase order, directly or through partners; a free trial; a free year of LanSchool with eligible Lenovo education devices. No prices are published | Published: free for up to 3 computers online at once; for a school, €499 the first year, then €299 a year; no per-PC charge |
| Languages | Software languages not stated (the website has many regional versions) | English and Lithuanian, every text |
| Integrations | Air syncs class lists with Google Classroom, ClassLink and Clever | The built-in list of computers with rooms |

## In the lesson

| Task | LanSchool | Classroom Manager |
|---|---|---|
| Watch student screens | Yes | Deliberately no |
| Show the teacher's screen, or a student's, to the class | Yes (a full-screen view locks student devices; a windowed view lets them work along) | No |
| Blank or lock screens | Yes | Yes, with your message |
| Messages, one-to-one chat, group chat, "raise hand" | Yes (raise hand in Air) | A message to the students; no chat window |
| Limit the web to approved sites, or block internet during tests | Yes | Block lists for websites and programs in Exam mode |
| Limit apps; see web, app and keystroke history (Classic) | Yes | Programs can be blocked in Exam mode; no web, app or keystroke history |
| Keyword alerts sent to a central reporting server (Classic) | Yes | No |
| Remote control: log in to student devices to install apps or updates while students work (Classic) | Yes | No remote view or control; software is installed from the Host |
| Tests and quizzes (up to 100 questions, self-grading), voting with CSV export | Yes | No |
| Send and collect files; push a website; launch an app; mute audio | Yes | Yes, files with an undo, collected by pattern into a folder per student; sound can be restricted in Exam mode |
| Limit printing; battery status (Air); co-teaching (Air) | Yes | Not in our feature list |

## Looking after the computers

| Task | LanSchool | Classroom Manager |
|---|---|---|
| IT tools | "IT admins" can "collect and report relevant data"; installing apps and updates through remote control (Classic); no itemised tools on the pages read | Install or uninstall software (installers, MSI, winget, registry files), Windows Update, inventory with CSV export, accounts, processes, scheduled tasks, start-up programs, registry, wallpaper, themes, keyboard layouts, renaming, clock sync |
| Schedules that catch up computers that were off | Not stated on the pages read | Yes |
| Diagnostics when something does not connect | Not stated on the pages read | Two health checkers and documented error codes |

## Which one fits

**Choose LanSchool** if you want teaching tools and screen visibility, with a locally hosted or a cloud edition, class rosters from Google Classroom, ClassLink or Clever, Chromebooks as well as Windows and Mac, and built-in tests. Ask for a quote and the system requirements, which its pages do not give.

**Choose Classroom Manager** if the work is keeping a Windows lab ready: software, updates, settings, accounts and exam restrictions, files out and back, with a flat published price, help with the rollout, and no screen capture or keystroke history of minors to justify under GDPR.
