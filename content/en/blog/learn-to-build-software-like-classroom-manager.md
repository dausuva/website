Classroom Manager is a Windows program with two halves: a teacher's console and a small service on every student computer. They talk over an encrypted connection on the school network. Nothing about that is magic, and the skills behind it can be learned in a sensible order. This is the order we would suggest, with the books we use. The full list is on [books for inspiration](../../books-for-inspiration/).

## Step 1: the basics of computer science

Start with a course that gives you the whole map. If you are a student, that is probably your [IB Diploma Computer Science](../../books-for-inspiration/#ib) course book. If you are learning alone, read [Code](../../books-for-inspiration/code-petzold/) by Charles Petzold to see how a computer works from the bottom up.

## Step 2: write programs

Pick one language and build small things. [Python Crash Course](../../books-for-inspiration/python-crash-course/) is a good first book. When you are ready for something deeper, [Structure and Interpretation of Computer Programs](../../books-for-inspiration/sicp/) teaches how programs are structured. If you want to work on Windows software like ours, learn C# with [C# in Depth](../../books-for-inspiration/csharp-in-depth/).

## Step 3: the craft of programming

Writing a program is not the same as writing one that other people can change in a year. [The Pragmatic Programmer](../../books-for-inspiration/pragmatic-programmer/), [Code Complete](../../books-for-inspiration/code-complete/), [Refactoring](../../books-for-inspiration/refactoring/) and [Test-Driven Development](../../books-for-inspiration/test-driven-development/) teach the habits: small steps, tests, and changing code safely.

## Step 4: architecture and design

Once programs get large, structure matters. [A Philosophy of Software Design](../../books-for-inspiration/philosophy-of-software-design/), [Clean Architecture](../../books-for-inspiration/clean-architecture/) and [Domain-Driven Design](../../books-for-inspiration/domain-driven-design/) are about keeping a system understandable. [Release It!](../../books-for-inspiration/release-it/) is about designing for failure, and [The Design of Everyday Things](../../books-for-inspiration/design-of-everyday-things/) is about designing for people.

## Step 5: Windows and security

Software that administers other people's computers must be safe. Start with [Threat Modeling](../../books-for-inspiration/threat-modeling/) and [Writing Secure Code](../../books-for-inspiration/writing-secure-code/). When you want to see inside the system, read [Windows Security Internals](../../books-for-inspiration/windows-security-internals/), and keep [Windows Internals](../../books-for-inspiration/windows-internals/) as a reference.

## Step 6: your own startup

Building something is half the job. Finding out whether anyone wants it is the other half. [The Mom Test](../../books-for-inspiration/mom-test/) is a short book on how to ask, and [The Lean Startup](../../books-for-inspiration/lean-startup/) is about learning in small, cheap steps.

You do not have to read every book. Read the one for the step you are on, build something, and come back for the next.
